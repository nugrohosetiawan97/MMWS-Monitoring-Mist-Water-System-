    Unduh data

    Format CSV ini langsung bisa diimpor ke tab Data Trafo & Umur di dashboard analisis (periode sebelum/sesudah mist). Riwayat di server disimpan 7 hari; arsip harian lengkap ada di folder data server.

    Impor riwayat bulan-bulan sebelumnya

    Data logsheet atau ekspor SCADA dihitung dengan model yang sama (IEC 60076-7) untuk mengisi FEQA harian, susut umur, dan pembanding sebelum/sesudah mist. Data impor tidak mengubah kendali mist.

    Kolom wajib: waktu + salah satu mva / mw / arus_a (sisi 20 kV). Opsional: ambien, rh, oti, wti_hv, wti_lv. Waktu YYYY-MM-DD HH:MM atau DD/MM/YYYY HH:MM. Pemisah koma, titik koma atau tab.
